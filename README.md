# 🍲 SOPA — Inteligência Espiritual

**Alimente sua vida espiritual, uma colherada de cada vez.**

O SOPA é um aplicativo cristão desenvolvido com o propósito de incentivar o crescimento espiritual por meio de pequenas atitudes, reflexões e práticas diárias.

Sua proposta é tornar a jornada de desenvolvimento espiritual mais acessível, pessoal e consistente, ajudando cada pessoa a cultivar hábitos que fortaleçam sua caminhada com Deus.

Mais do que um aplicativo, o SOPA é um convite à transformação de vidas.

## 🎯 Propósito

Conquistar vidas para Jesus, incentivando o desenvolvimento de uma vida espiritual consciente, constante e fundamentada nos ensinamentos de Cristo.

O projeto busca aproximar a espiritualidade do cotidiano, respeitando diferentes tradições cristãs e utilizando uma linguagem acessível, acolhedora e inclusiva.

## 💡 Conceito

A experiência do SOPA utiliza uma metáfora bastante simples: assim como nosso corpo precisa de alimento diariamente, nossa vida espiritual também precisa ser nutrida.

O usuário participa da construção de sua própria receita espiritual, selecionando ingredientes que representam valores e práticas importantes para sua caminhada.

A partir dessa receita, estabelece objetivos e realiza pequenas ações diárias, chamadas de **Colheradas**.

## ✨ Funcionalidades

O MVP contempla os seguintes recursos:

- **Ingredientes:** seleção e organização de valores e princípios que representam a vida espiritual.
- **Receita:** definição de um ingrediente principal, ingredientes complementares e um objetivo semanal.
- **Colherada:** registro de pequenas atitudes diárias, incentivando a constância na jornada espiritual.
- **Lembretes:** notificações para ajudar a manter a regularidade das práticas.

## 🚀 Executando o projeto

### Pré-requisitos

- Node.js
- npm
- Expo CLI (utilizado por meio do `npx`)
- Git

### Instalação

Clone o repositório:

```bash
git clone https://github.com/luiz-leite-dev/sopa-app.git
```

Acesse o diretório:

```bash
cd sopa-app
```

Instale as dependências:

```bash
npm install
```

### Executando

Inicie o servidor de desenvolvimento:

```bash
npx expo start
```

Para executar em plataformas específicas:

```bash
npm run android
```

```bash
npm run ios
```

```bash
npm run web
```
